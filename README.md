This resource pack adds book textures for each enchantment and curse. Books appear thicker when they are combined or are at their maximum level.

This pack works in vanilla and is NOT compatible with versions before 1.21.5, even when using mods such as Optifine or CIT.

See the [Modrinth page](https://modrinth.com/resourcepack/kitlashs-enchanted-books) to preview and download the pack.
